vkc is a self-describing command-line client for Vikunja: instead of hardcoding Vikunja's API surface, it discovers actions at runtime from the OpenAPI spec every Vikunja instance serves at `/api/v1/docs.json`, generates its command tree and `--help` from that spec, attaches a locally stored API token, submits requests over HTTP, and renders the JSON results. The outcome is a CLI that never goes stale — when a Vikunja instance gains new endpoints, vkc surfaces them without a code change.
